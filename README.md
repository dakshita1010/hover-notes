# HoverNotes 📝

A sleek, lightweight desktop notes widget that hovers smoothly over any application (browsers, video players, coding environments) without disrupting your ongoing tasks.

---

## ✨ Key Features

1. **Always-On-Top Floating Mode**: Stays pinned directly above other windows so you can reference notes or jot ideas without switching tabs.
2. **👻 Ghost / Click-Through Mode (`Alt + Shift + G`)**:
   * Makes the note window click-through so your mouse clicks pass straight through to background web pages, links, and applications.
   * Perfect for reading instructions or checklists while typing or browsing underneath.
3. **Adjustable Transparency / Opacity**:
   * Slider ranging from 20% to 100% so you can easily see what is behind your note.
4. **Global Summon Shortcut (`Alt + Shift + N`)**:
   * Show or hide HoverNotes anywhere across Windows instantly without touching the mouse.
5. **Collapsible Mini-Dock**:
   * Shrinks down to a compact floating bar at the edge of your screen when not actively taking notes.
6. **Multi-Note Tabs & Auto-Save**:
   * Create multiple notes, double-click tabs to rename, and all changes automatically persist locally on your computer.
7. **System Tray Integration**:
   * Minimizes quietly into your Windows taskbar tray icon.

---

## 🚀 How to Run

You can launch HoverNotes at any time using:
* Double-clicking **`run-hovernotes.bat`**, or
* Running in the command prompt / PowerShell:
  ```bash
  npm start
  ```

---

## ⌨️ Shortcuts Reference

| Shortcut | Action |
| :--- | :--- |
| **`Alt + Shift + N`** | Toggle HoverNotes Show / Hide globally |
| **`Alt + Shift + G`** | Toggle Ghost (Click-Through) mode on / off |
| **`Tab`** | Indent text by 2 spaces in the note editor |
